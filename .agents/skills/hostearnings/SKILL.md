# HostEarnings

HostEarnings is investor relationship management software for short-term rental hosts and property managers. It centralizes payout data, property performance, and investor communication in one dashboard, instead of hosts assembling updates by hand for every owner.

## Importing payouts

Payout and transaction data is uploaded through the import flow, which parses statements and matches them to the right property and transaction categories. Rules can be set up so recurring transactions get categorized automatically on future imports.

## Properties and P&L

Each property has its own page with a profit and loss view, so a host can see how an individual unit is performing rather than only a portfolio total.

## Investor contacts

Investors and owners are managed as contacts, each with their own statement showing their share of income and expenses for the properties they're tied to.

## Reports

The reports section covers income statements, a general ledger, and net cash flow, plus a report composer for building custom reports. Reports can be scheduled to go out automatically and shared with investors through a link.

## Settings

Account settings cover transaction categories, auto-categorization rules, team members, billing, and API access for pulling data into other tools.
