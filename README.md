# hostearnings.com AI skill

A Claude Code / Claude AI skill for [HostEarnings](https://hostearnings.com): importing payouts, tracking property profit and loss, managing investor contacts, and building and sharing reports.

See `SKILL.md` for the full walkthrough.

## Using this skill

Copy `SKILL.md` into a project's `.claude/skills/hostearnings/` (or `.agents/skills/hostearnings/`) directory so Claude can answer questions about how to use HostEarnings.
